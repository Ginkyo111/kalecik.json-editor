# Éditeur Web V2 Final

Ce projet contient l'application web interactive **Éditeur V2 Final** hébergée via une page HTML autonome.

## 📁 Contenu du projet

- `index.html` : Application web complète (HTML, CSS, JavaScript).
- `README.md` : Document d'information et instructions de déploiement.

## 🚀 Utilisation locale

Pour exécuter le projet sur votre ordinateur :
1. Téléchargez et dézippez le dossier.
2. Double-cliquez sur le fichier `index.html` pour l'ouvrir dans n'importe quel navigateur web (Chrome, Firefox, Edge, Safari).

## 🌐 Déploiement sur GitHub & GitHub Pages

Pour héberger ce projet gratuitement sur Internet via GitHub :

1. Créez un nouveau dépôt sur [GitHub](https://github.com/).
2. Déposez les fichiers `index.html` et `README.md` dans le dépôt.
3. Allez dans **Settings** > **Pages**.
4. Sous **Branch**, sélectionnez `main` (ou `master`) et conservez `/ (root)`, puis cliquez sur **Save**.
5. Après quelques instants, votre application sera accessible à l'adresse `https://<votre-compte>.github.io/<nom-du-depot>/`.
